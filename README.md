# The Arnx Food & Drinks — 100% Pure Vegetarian Delights 🌿👑

A royal, luxury-tier restaurant and artisanal mocktail lounge website crafted with rich emerald and imperial gold aesthetics, glassmorphism, and complete dynamic interactivity.

---

## ✨ Features

- **🏆 Regal Brand Identity**:
  - Deep emerald green (`#071911`, `#0f3827`) & warm radiant gold (`#f59e0b`, `#d97706`) color scheme.
  - Official SVG Logo with the 100% Pure Veg emblem (Green Dot certification).
  - Editorial luxury typography featuring Google Fonts *Playfair Display* and *Plus Jakarta Sans*.

- **🍽️ Interactive Culinary Menu**:
  - Live real-time search across all dishes and mocktails.
  - Category tabs: *Royal Thalis*, *Tandoor & Starters*, *Royal Curries & Naans*, *Artisanal Drinks*, *Woodfired Pizzas*, and *Divine Sweets*.
  - Dietary filter chips: *All*, *Chef's Specials*, *Bestsellers*, and *Jain Friendly*.
  - Rich Quick View modal displaying ingredients, calories, protein, and chef's tasting notes.

- **🛒 Slide-Over Cart & Online Ordering Drawer**:
  - Add / remove items with instant quantity counters (`+` / `-`).
  - Toggle between *Home Delivery*, *Dine-in Pre-order*, and *Takeaway*.
  - Promo code system with instant validation:
    - `ARNXFIRST` → Flat 15% OFF
    - `VEGLOVE` → Flat ₹100 OFF
    - `ROYAL20` → 20% OFF on grand orders
  - Bill summary with subtotal, 5% restaurant GST, and delivery calculations.
  - Interactive Checkout modal with live simulated royal kitchen order tracker!

- **🥂 Royal Table Reservation System**:
  - Date & time slot picker (Lunch & Dinner slots).
  - Guest counter (2 to 12+ guests) and seating zone preference (*Royal Emerald Dining Hall*, *Starlight Rooftop Garden*, *Private VIP Suite*).
  - Instant digital Royal Booking Pass generator with unique booking ID (`ARNX-XXXXXX`).

- **🍸 Artisanal Drinks & Mocktails Lounge**:
  - Dedicated molecular mocktails showcase featuring *Emerald Kiwi Mint Cooler*, *Royal Golden Saffron Refresher with 24K Gold shimmer*, and *Smoked Hibiscus Mist*.

- **🌿 The Sacred Kitchen (Our Pure Veg Legacy)**:
  - Strict 100% vegetarian guarantee (Zero meat, zero egg, zero cross-contamination).
  - Vedic A2 Gir cow ghee and cold-pressed oils.
  - Dedicated Jain cooking stations and utensils.

- **📱 Direct Concierge & WhatsApp Ordering**:
  - Floating WhatsApp ordering button for instant concierge communication.
  - Sticky bottom order bar on mobile and desktop when items are placed in the cart.

---

## 🚀 How to Run Locally

You can preview the website by simply opening `index.html` in any web browser, or by starting a local server:

### Using Python (Installed & Ready):
```bash
python -m http.server 8080
```
Then visit: **[http://localhost:8080](http://localhost:8080)**
